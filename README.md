# Ice Pak Hockey

The website of the Ice Pak hockey team, at [icepakhockey.com](https://icepakhockey.com).

- `site/` is the site: an Astro app on Cloudflare Workers with a D1 database.
- `CONTEXT.md` is the glossary.
- `docs/site-rebuild-decisions.md` has the decisions and the order of work.
- `AGENTS.md` has the rules for coding agents.

The git tag `old-site` has the Next.js site that ran until November 2026.
